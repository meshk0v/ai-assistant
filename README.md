# ИИ-ассистент

Сайт с ИИ-ассистентом, который отвечает на вопросы пользователей. Ответы приходят потоком, слово за словом.

- Приветственный экран с примерами вопросов
- Чат с историей диалогов (хранится в браузере; диалоги можно переключать и удалять)
- Поле ввода с автоматической высотой; Enter — отправить, Shift+Enter — новая строка
- Индикатор загрузки, кнопка «Стоп», повтор запроса после ошибки
- Ответы в Markdown: списки, таблицы, блоки кода с копированием
- Светлая и тёмная тема, адаптивная вёрстка для телефона

## Запуск

Нужен Node.js 20.12 или новее.

```bash
npm install
cp .env.example .env   # впишите ANTHROPIC_API_KEY
npm start              # http://localhost:3000
```

Без ключа сайт запускается в **демо-режиме** с тестовыми ответами, так что интерфейс можно проверить сразу.

## Подключение модели

Ключ API хранится только на сервере, браузер его не видит. Фронтенд отправляет историю диалога на `POST /api/chat`. Сервер ([server.js](server.js)) вызывает Claude API через официальный SDK `@anthropic-ai/sdk` и пересылает ответ в браузер потоком Server-Sent Events:

```
data: {"type":"delta","text":"…"}     фрагмент ответа
data: {"type":"notice","message":"…"} предупреждение (например, ответ обрезан)
data: {"type":"error","message":"…"}  ошибка
data: {"type":"done"}                 конец ответа
```

Настройки в `.env`:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ API |
| `LLM_MODEL` | `claude-opus-5-5` | Модель |
| `LLM_EFFORT` | `low` | Глубина рассуждений: `low`…`max`. Чем выше, тем точнее, но медленнее и дороже |
| `LLM_MAX_TOKENS` | `16000` | Максимальная длина ответа |
| `LLM_SYSTEM_PROMPT` | см. server.js | Роль и тон ассистента |
| `PORT` | `3000` | Порт сервера |

Чтобы подключить другую модель или провайдера, замените вызов модели в обработчике `/api/chat`. Формат событий при этом сохраните, и фронтенд менять не придётся.

## Сайт на GitHub Pages

Фронтенд публикуется на https://meshk0v.github.io/ai-assistant/ автоматически при каждом пуше в `main` (см. [.github/workflows/pages.yml](.github/workflows/pages.yml)). GitHub Pages умеет отдавать только статические файлы, поэтому там сайт работает в демо-режиме. Ключ API нельзя класть во фронтенд: его увидит любой посетитель.

Чтобы на Pages отвечала настоящая модель:

1. Разверните `server.js` на любом Node-хостинге (Render, Railway, VPS) с переменными `ANTHROPIC_API_KEY` и `ALLOWED_ORIGINS=https://meshk0v.github.io`.
2. Укажите адрес этого сервера в [public/config.js](public/config.js): `window.ASSISTANT_API_URL = "https://…"`.
3. Запушьте изменения. Pages обновится сам.

## Структура

```
server.js            Express-сервер и прокси к модели
public/config.js     адрес сервера для фронтенда
public/index.html    разметка
public/styles.css    стили и темы
public/app.js        логика чата, история, стриминг
public/markdown.js   безопасный рендер Markdown (HTML экранируется)
```
